# Backend - Estructura profesional

- **controllers/**: Lógica de negocio, recibe peticiones y llama a servicios.
- **models/**: Esquemas de Mongoose (colecciones de la base de datos).
- **routes/**: Endpoints de la API.
- **services/**: Lógica de acceso y operaciones con la base de datos.
- **middlewares/**: Funciones middleware de Express (autenticación, validación, logs, errores, etc.).
- **utils/**: Utilidades y helpers.
- **index.js**: Punto de entrada principal de la aplicación.
